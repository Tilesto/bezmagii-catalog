Сайт **#0** из челленджа «Сайт через день» блога **Без магИИ**: зрители предлагают идею, я делаю
сайт с ИИ и выкладываю в прод. Честно: сколько часов, где ИИ тупил, что пришлось чинить руками.

- Сайт: https://bezmagii.site
- Все сайты челленджа: https://bezmagii.site

## Стек

Фронт — React + Vite + SCSS modules. Бэк — Fastify + SQLite (Drizzle). Полоса челленджа, подвал,
тема, статистика и деплой — из моей заготовки, общей для всех сайтов челленджа.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev        # фронт http://localhost:5173, API http://127.0.0.1:3000
npm test           # тесты бэка
```
